# SENG 265 – Software Development Methods

Coursework and projects completed for SENG 265 at the University of Victoria.

## Blogging System

A modular blogging system developed in Python featuring user authentication,
blog and post management, persistent data storage, and unit testing.

### Key Concepts
- Object-oriented programming
- CRUD operations
- DAO design pattern
- JSON and Pickle persistence
- Unit testing with unittest
- Exception handling
